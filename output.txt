2. ROOT CAUSE & IMPLEMENTATION: P0 HOTFIX REACT ERROR #31
--------------------------------------------------------------------------------
Error: Minified React error #31: Objects are not valid as a React child (found: object with keys {label, value})

Root Cause:
In frontend/src/research3d/Outcomes3D.jsx (lines 338-356), hudMetrics was supplied as an array of objects:
  hudMetrics={[
    { label: 'Crop', value: data.crop },
    { label: 'Season', value: data.season },
    ...
  ]}
In frontend/src/research3d/Research3DScene.jsx (line 387):
  {hudMetrics.map((m, idx) => (
    <React.Fragment key={idx}>
      <span>|</span>
      <span>{m}</span>  <-- Threw React Error #31 because m was a raw {label, value} object
    </React.Fragment>
  ))}
Furthermore, line 312 in the 2D accessible fallback table called metric.split(':'), which threw TypeError when metric was an object.

Resolution:
1. Implemented defensive formatHudMetric() normalizer in Research3DScene.jsx that handles:
   - Objects with {label, value, color}: extracts primitive strings and renders label: value.
   - String metrics with ':' delimiter (e.g. "Storage: 120/450 mm"): splits label and value cleanly.
   - Raw primitive values: converts to strings safely.
2. Formatted both 3D HUD stats badge and 2D accessible fallback table with clean text and colors.
3. Added P0 Regression Test 15 in frontend/src/runtimeRepairs.test.js asserting that raw {label, value} objects are safely normalized to primitive text without throwing.
