2.1 FAO-56 Ks Water-Stress Formulation & Cuticular Boundary:
- Classical FAO-56 Chapter 8 Formulation (Eq. 84):
    Ks = (TAW - Dr) / ((1 - p) * TAW) = S / S_threshold   for S < S_threshold
    Ks = 1.0                                                for S >= S_threshold
- FieldShift Implementation (experimentSimulationEngine.js:L474-485):
    let ks = 1.0;
    if (infiltratedStorage < sThresholdMm) {
      ks = Math.max(0.05, infiltratedStorage / sThresholdMm);
      stressDaysCount++;
    }
    const eta = Math.min(infiltratedStorage, etc * ks);
    currentSoilWaterMm = infiltratedStorage - eta;
- Boundary Verification & Agronomic Justification:
  * S >= S_threshold: Ks = 1.0 (smooth continuous transition at threshold).
  * 0 < S < S_threshold: Ks decreases linearly with available root-zone storage.
  * S = 0 (Permanent Wilting Point): Ks = 0.05 (empirical cuticular buffer), ETa = min(0, etc * 0.05) = 0.00 mm.
  * Soil water storage never underflows below 0.00 mm; mass conservation is strictly preserved.
